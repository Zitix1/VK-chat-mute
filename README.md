# ZTX Chat Mute

Локальный мьют людей в чатах [ВКонтакте](https://vk.com).  
Сообщения выбранного человека скрываются только у тебя в Chrome. Это не блок, не кик и не уведомление собеседнику.

Расширение от **ZTX inc.**

## Установка

Магазин Chrome пока не используется. Ставится вручную:

1. Скачай ZIP этой ветки: **Code → Download ZIP**
2. Распакуй папку
3. Открой `chrome://extensions`
4. Включи **Режим разработчика**
5. **Загрузить распакованное расширение**
6. Укажи папку репозитория (там лежит `manifest.json`)
7. Обнови вкладку `vk.com` / `vk.ru`

## Как пользоваться

- Открой беседу
- Наведи на имя человека — справа появится **🔇**
- Нажми, чтобы скрыть все его сообщения
- Список и снятие мута — иконка расширения справа в Chrome
- Можно добавить человека по `id`, ссылке `vk.com/id123` или `@username`

Настройки в окне расширения:

- плагин вкл/выкл
- жёсткий режим: полностью прятать сообщения

## Что хранится

Только у тебя в `chrome.storage.sync`:

- id или ник замьюченного
- имя для отображения в списке
- тумблеры настроек

На серверы разработчика ничего не уходит.  
Ключ мута — один: числовой VK id, если его нет — ник. Имя не используется как идентификатор.

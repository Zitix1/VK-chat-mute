# ZTX Chat Mute

Локальный мьют людей в чатах ВКонтакте.  
Сообщения скрываются только у тебя в Chrome.

## Установка

1. Скачай ZIP: **Code → Download ZIP**
2. Распакуй
3. Открой `chrome://extensions`
4. Включи **Режим разработчика**
5. **Загрузить распакованное расширение**
6. Укажи папку с `manifest.json`
7. Обнови вкладку VK

## Как пользоваться

В беседе наведи на имя — справа появится **🔇**.  
Список мутов и снятие — иконка расширения в Chrome.
